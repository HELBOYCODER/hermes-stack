🔑 دسترسی گیت‌هاب

یک Personal Access Token با اسکوپ‌های repo و workflow لازم است تا ویزارد بتواند ریپو بسازد و سکرت‌ها را ست کند.

1

روی این لینک آماده بزن — صفحه ساخت توکن با تیک‌های درست باز می‌شود. نام بگذار، expiration انتخاب کن و Generate token را بزن.

2

توکن ساخته‌شده (ghp_…) را کپی و اینجا بچسبان. توکن فقط در مرورگرت می‌ماند.

🔒 ویزارد یک فایل استاتیک است؛ توکن‌ها فقط به api.github.com، huggingface.co و api.telegram.org می‌روند — نه هیچ سرور دیگری. بعد از اتمام استقرار، از همان صفحه گیت‌هاب توکن را حذف/rotate کن (الگوی امن).

🤗 توکن هاگینگ‌فیس

توکن با نقش write لازم است تا Space ساخته شود، فایل‌ها آپلود شوند و سکرت‌های Space ست گردد.

1

در تنظیمات توکن‌ها یک توکن جدید با نقش Write بساز (یا fine-grained با دسترسی Write به Contents).

آدرس نهایی برنامه‌ات این شکلی می‌شود: https://USER-hermes-stack.hf.space

💬 ربات تلگرام

در تلگرام به @BotFather برو، دستور /newbot را بزن و توکن 123456:AA… را اینجا بچسبان.

برای «دریافت از پیام‌ها»: اول در تلگرام به ربات خودت یک /start بده (یا هر پیامی بفرست)، بعد این دکمه را بزن — ویزارد آخرین پیام‌دهنده‌ها را نشان می‌دهد؛ روی هر کدام بزنی انتخاب می‌شود. این کار جلوی استفاده‌ی دیگران از ربات تو را می‌گیرد.
